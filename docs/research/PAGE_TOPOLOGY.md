# Page topology

The clone is a 14-route, viewport-locked presentation. Every route uses the same fixed 1440x1000 experience frame and swaps a route-native scene inside the centered slide canvas.

1. `/` — Home
2. `/brand-message/` — Brand Message
3. `/ci-update/` — CI Update
4. `/vision-visual/` — Vision Visual
5. `/funtech-way/` — FunTech Way
6. `/megavolt-creative/` — A Million-Volt Creative
7. `/breakers-of-victory/` — Breakers of Victory
8. `/all-for-fun/` — All for Fun
9. `/logo-details/` — Logo Details
10. `/logo-variation/` — Logo Variation
11. `/10th-special-item/` — 10th Special Item
12. `/ending-message/` — Ending Message
13. `/we-are-funtech/` — We Are FunTech
14. `/fin/` — Fin

The shared shell contains a 200px scroll-snapped thumbnail rail, a flexible scene panel, 56px bottom navigation, three theme controls, and a full-canvas 14-item menu. Wheel, rail, menu, previous, and next navigation all update the real history URL.
